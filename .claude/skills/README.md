# Skills incluidas en el proyecto

Claude Code carga estas skills automáticamente al abrir esta carpeta, sin instalar nada.

| Skill | Para qué | Autoría |
|---|---|---|
| `animate` | Decidir si algo debe animarse y con qué curva y duración | Skill de terceros. Recoge la filosofía de animación de [Emil Kowalski](https://emilkowal.ski/) |
| `design-taste-frontend` | Evitar diseño de plantilla en páginas de aterrizaje y rediseños | Skill de terceros |
| `no-ai-slop` | Evitar textos con pinta de generados por IA | Licencia MIT (ver `no-ai-slop/LICENSE`). Derivada de [stop-slop](https://github.com/hardikpandya/stop-slop), de Hardik Pandya |

`animate` y `design-taste-frontend` se incluyen tal cual, sin modificar, para que el equipo trabaje con el mismo criterio con el que se construyó esta web. No llevan archivo de licencia. Si eres su autor y prefieres que no estén aquí, escribe a Gerencia@agosan.net y se retiran.

Los plugins que sí se instalan aparte (`ui-ux-pro-max`, `playwright`, `frontend-design`, `superpowers`) están en `scripts/setup-claude.sh` y `scripts/setup-claude.ps1`.
